# PDF 文档生成

生成高质量 PDF 文档，支持排版、分页与内嵌资源。

## 安装

从 GitHub 装（需要本机有 `git`）：

```bash
npx skills add SeaWork-Labs/minimax-pdf#v1.0.1 --skill minimax-pdf
```

从市场索引装（纯 HTTPS，国内网络可达）：

```bash
npx skills add https://skills.seaharness.cn --skill minimax-pdf
```

## 内容

技能正文在 `skills/minimax-pdf/payload/`。这些文件由转换器从市场归档逐字节搬来，改动请直接改 `skills/minimax-pdf/payload/`，不要反向同步。版本以 git tag 为准。
